# Historical research sources

These articles preserve the earlier manuscript replication, simulation,
variable-importance, hyperparameter-search, and comparison sources. They may
refer to earlier ReSurv interfaces, Python-based models, external data, missing
figure/bibliography assets, or additional research dependencies. Their code is
not validated against the current package and they are not distributed as
package vignettes or built into the current website.

For the supported API and executable examples, use
[Getting started](../../vignettes/getting-started.Rmd) and the generated R help.
