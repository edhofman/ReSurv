# ReSurv: Individual claim-count reserving

Fit reverse-time hazard models with
[`ReSurv`](https://edhofman.github.io/ReSurv/reference/ReSurv.md),
following preprocessing with
[`IndividualDataPP`](https://edhofman.github.io/ReSurv/reference/IndividualDataPP.md).
Use
[`ReSurvCV`](https://edhofman.github.io/ReSurv/reference/ReSurvCV.md)
for hyperparameter selection,
[`predictReserve`](https://edhofman.github.io/ReSurv/reference/predictReserve.md)
for count forecasts, and
[`Score_Reserving`](https://edhofman.github.io/ReSurv/reference/Score_Reserving.md)
to evaluate realized claims.
